# QuizzMatch

Quiz gratuits en français et en anglais, défis entre amis et classement de la semaine.
En ligne sur https://quizzmatch.com

- `index.html` : le jeu (une seule page)
- `questions.js`, `questions-plus.js` : questions en français ; `questions-en.js` : version anglaise
- `outils/pages.js` : régénère les pages par quiz et `sitemap.xml` (`node outils/pages.js`)
